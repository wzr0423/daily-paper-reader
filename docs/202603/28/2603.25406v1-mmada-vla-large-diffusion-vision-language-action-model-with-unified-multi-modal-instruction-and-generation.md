## 摘要
视觉-语言-动作（VLA）模型旨在根据视觉观测和自然语言指令控制机器人进行操作。然而，现有的分层和自回归范式通常会引入架构开销，面临时间不一致性和长时程误差累积的问题，并且在不添加额外模块的情况下缺乏捕捉环境动力学的机制。为此，我们提出了 MMaDA-VLA，这是一个完全原生的预训练扩散 VLA 大模型，在单一框架中统一了多模态理解与生成。我们的核心思想是一种原生的离散扩散公式，它将语言、图像和连续机器人控制嵌入到一个离散的 token 空间中，并通过掩码 token 去噪训练单一骨干网络，以并行地联合生成未来目标观测和动作块（action chunk）。迭代去噪实现了全局、无序的细化，在不依赖辅助世界模型的情况下，将动作锚定在预测的未来视觉结果中，从而提高了长时程一致性。在仿真基准测试和真实世界任务中的实验表明，该模型达到了最先进的性能，在 LIBERO 上实现了 98.0% 的平均成功率，在 CALVIN 上达到了 4.78 的平均长度。

## Abstract
Vision-Language-Action (VLA) models aim to control robots for manipulation from visual observations and natural-language instructions. However, existing hierarchical and autoregressive paradigms often introduce architectural overhead, suffer from temporal inconsistency and long-horizon error accumulation, and lack a mechanism to capture environment dynamics without extra modules. To this end, we present MMaDA-VLA, a fully native pre-trained large diffusion VLA model that unifies multi-modal understanding and generation in a single framework. Our key idea is a native discrete diffusion formulation that embeds language, images, and continuous robot controls into one discrete token space and trains a single backbone with masked token denoising to jointly generate a future goal observation and an action chunk in parallel. Iterative denoising enables global, order-free refinement, improving long-horizon consistency while grounding actions in predicted future visual outcomes without auxiliary world models. Experiments across simulation benchmarks and real-world tasks show state-of-the-art performance, achieving 98.0% average success on LIBERO and 4.78 average length on CALVIN.

#### 1. 核心问题与整体含义（研究动机和背景）
视觉-语言-动作（VLA）模型是机器人操作领域的核心，旨在将视觉感知和语言指令转化为控制动作。然而，现有模型存在三大痛点：
*   **架构冗余**：分层架构（VLM + 策略头）增加了训练成本和信息损失。
*   **时间不一致性**：自回归生成动作序列容易导致长程任务中的误差累积。
*   **缺乏动力学建模**：大多数模型无法预测动作对环境的影响（即缺乏“世界模型”能力），导致动作缺乏视觉依据。
**MMaDA-VLA** 的提出是为了构建一个**完全原生、预训练的离散扩散 VLA 模型**，在单一框架内统一多模态理解与生成，通过并行预测“未来目标观测”和“动作序列”来解决上述问题。

#### 2. 方法论：核心思想与关键技术
*   **统一离散 Token 空间**：将语言（LLaDA 分词器）、图像（MAGVIT-v2 量化器）和连续动作（256 槽位离散化）全部映射到统一的离散 Token 空间，使用单一骨干网络处理。
*   **原生离散扩散公式**：采用掩码 Token 建模（Masked Token Modeling）。在训练时随机掩码目标图像和动作 Token；在推理时，通过迭代去噪（Iterative Denoising）从全掩码状态恢复出清晰的预测结果。
*   **并行生成机制**：模型在同一次迭代中并行生成“未来目标观测（Goal Observation）”和“动作块（Action Chunk）”。这种设计让动作生成能够隐式地参考预测的视觉演变，增强了动力学感知。
*   **混合注意力机制（Hybrid Attention）**：模态内部采用双向全注意力（Bidirectional Full Attention）以实现全局信息交换，模态之间采用因果注意力（Causal Attention）以确保信息流向正确，避免推理时的信息泄露。
*   **KV 缓存优化**：为了应对扩散模型推理慢的问题，引入了训练无关的缓存框架，通过选择性刷新 Token 来提高实时控制频率。

*   **长程一致性强**：迭代去噪过程允许模型对动作轨迹进行全局细化，有效缓解了自回归模型的误差累积问题。
*   **动力学感知**：原生支持未来视觉预测，使机器人能够“预见”动作后果，从而做出更合理的决策。

*   **视觉生成精度**：生成的未来观测图像在细节（如夹具几何形状、微小物体）上存在模糊，视觉保真度有待提高。

*   **数据依赖**：模型性能高度依赖于大规模高质量的跨具身预训练数据，对于缺乏数据的特定领域任务，微调效果可能受限。
