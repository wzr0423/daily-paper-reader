## 摘要
手内物体重定向需要精确的物体位姿估计，以处理复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有解决方案往往依赖于多摄像头设置或昂贵的光线追踪。我们提出了一种用于单目 RGB 手内重定向的从仿真到现实（sim-to-real）框架，该框架集成了 3D 高斯泼溅（3DGS）以弥合视觉上的 sim-to-real 差距。我们的核心见解是在高斯表示空间中执行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了写实的、随机化的视觉数据。操纵策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型都可以在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指手上验证了该系统，证明了即使在具有挑战性的光照条件下，也能对五种不同的物体进行鲁棒的重定向。我们的结果强调了高斯泼溅是实现仅依靠 RGB 的灵巧操纵的一条实用路径。有关硬件部署的视频和更多补充材料，请参阅项目网站：https://rffr.leggedrobotics.com/works/viserdex/

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. ### 1. 核心问题与整体含义（研究动机和背景）
灵巧手的手内重定向（In-hand Reorientation）是机器人学中的经典难题，要求系统能够精确感知物体位姿并进行复杂的动力学控制。
*   **研究动机**：现有的基于深度强化学习（DRL）的方案通常依赖多摄像头设置、昂贵的深度传感器或触觉阵列。虽然单目RGB相机成本低且语义丰富，但在仿真到现实（Sim-to-Real）迁移中存在巨大的“视觉鸿沟”。
*   **核心挑战**：传统基于网格（Mesh）的渲染器难以兼顾高保真度和高吞吐量，且标准的光线追踪（Ray Tracing）计算成本极高，难以支持大规模的领域随机化（Domain Randomization）。

### 2. 方法论：核心思想与关键技术
ViserDex 提出了一个解耦的感知-控制框架，核心在于利用 **3D Gaussian Splatting (3DGS)** 弥合视觉差距。

*   **3DGS 集成与预渲染增强（Pre-rasterization Augmentations）**：
    *   **核心思想**：不直接在生成的2D图像上做增强，而是在渲染前的3D高斯空间中对球谐系数（SH）进行扰动。
    *   **技术细节**：通过对高斯点进行空间聚类（Spatial Clustering）和颜色聚类（Color Clustering），模拟局部阴影、材质变化和全局光照（Global Shift）。这种方法避免了昂贵的光线追踪，同时保持了物理一致性。
    *   **公式背景**：利用球谐函数（Spherical Harmonics）捕捉视图相关的颜色效果，通过改变0阶（基础色）和高阶（高频高光）系数实现光照随机化。
*   **控制策略训练**：
    *   **教师-学生蒸馏**：首先训练一个拥有全状态特权信息的“教师”策略，然后将其蒸馏到仅依赖噪声观测（包括视觉位姿估计）的递归“学生”策略中。
    *   **性能驱动的课程学习（Performance-based Curriculum）**：根据智能体的平均连续成功次数，动态增加任务难度（如正则化惩罚、动作延迟、时间窗口缩减），显著提升了训练效率。
*   **位姿估计器**：采用 ResNet-34 骨干网络回归物体的 9 个关键点（8个顶点+质心），通过 Rigid Procrustes 算法解算出 6D 位姿。

### 3. 实验设计
*   **硬件平台**：16自由度 Allegro Hand，手腕安装单目 Intel RealSense D435i 相机。
*   **实验物体**：5 种具有挑战性的几何体（立方体、3D 打印玩具、小黄鸭、药瓶、地球仪）。
*   **对比基准（Benchmarks）**：
    *   **感知对比**：标准平铺渲染（Standard Tiled）、带域随机化的平铺渲染（DR Tiled）、原生 3DGS（无预渲染增强）。
    *   **控制对比**：与 OpenAI 的 DeXtreme 框架在相同物体上进行对比。
*   **场景设置**：分为“名义光照”（标准白光）和“对抗性光照”（低照度、动态彩色点光源）。

### 4. 资源与算力
论文强调了该框架对计算资源的友好性：
*   **硬件**：使用单台工作站，配备 Intel i9 CPU 和 **NVIDIA RTX 6000 Ada GPU**（部分实验使用 RTX 4090）。
*   **训练时长**：
    *   **教师策略**：简单物体约 26 小时，复杂物体约 90 小时。
    *   **学生蒸馏**：约 16 小时。
*   **效率优势**：3DGS 渲染吞吐量比传统渲染器快 1.6 倍；在 1024 个并行环境中，3DGS 仅需 12GB 显存，而传统渲染器需 34GB。

### 5. 实验数量与充分性
*   **实验规模**：针对 5 种物体分别进行了训练和测试，每种物体在真实硬件上进行了 5 次独立运行以统计连续成功次数（CS）。
*   **消融实验**：详细评估了四种预渲染增强策略（随机噪声、空间聚类、颜色聚类、全局偏移）对位姿估计准确性的贡献。
*   **客观性**：实验涵盖了从几何简单到复杂的物体，并引入了极端的对抗性光照环境，验证了系统的鲁棒性边界。

### 6. 主要结论与发现
*   **3DGS 的优越性**：在对抗性光照下，ViserDex 的位姿估计准确率（56.3%）显著高于最强的基线 DR Tiled（47.2%）。
*   **增强策略的重要性**：消融实验证明，“全局偏移（Global Shift）”是弥合视觉鸿沟最关键的因素，移除它会导致性能崩溃。
*   **硬件表现**：在真实世界中，系统实现了平均 37.6 次（名义光照）和 25.4 次（对抗光照）的连续重定向成功，超越了之前的视觉方案。

### 7. 优点（亮点）
*   **高效性**：首次证明了在单台消费级 GPU 上即可完成复杂的灵巧操作视觉策略训练，打破了以往需要大规模计算集群的限制。
*   **视觉鲁棒性**：通过在 3D 高斯空间进行增强，成功解决了单目 RGB 在复杂光照和严重遮挡下的位姿估计失效问题。
*   **课程学习简化**：提出的性能驱动课程学习替代了复杂的自动域随机化（ADR），降低了调参难度。

### 8. 不足与局限
*   **实例特定（Instance-specific）**：目前的方法仍需为每个物体单独训练位姿估计器和策略，缺乏对未知物体的通用泛化能力。
*   **物理建模偏差**：在药瓶实验中表现较差，原因是仿真中未能准确建模瓶身标签的极低表面摩擦力。
*   **遮挡限制**：虽然对部分遮挡有鲁棒性，但视觉方案在物体被手指完全包裹时仍存在感知盲区，未来可能需要结合触觉感知。
