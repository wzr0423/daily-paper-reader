## 摘要
手内物体重定向需要精确的物体位姿估计，以处理复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有解决方案往往依赖于多摄像头设置或昂贵的光线追踪。我们提出了一个用于单目 RGB 手内重定向的从仿真到现实（sim-to-real）框架，该框架集成了 3D 高斯泼溅（3DGS）以弥合视觉上的虚实迁移差距。我们的核心见解是在高斯表示空间中进行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了逼真的、随机化的视觉数据。操纵策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型都可以在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指手上验证了该系统，证明了即使在具有挑战性的光照条件下，也能对五种不同的物体进行鲁棒的重定向。我们的结果强调了高斯泼溅是实现仅靠 RGB 的灵巧操纵的一条实用路径。有关硬件部署的视频和更多补充材料，请参阅项目网站：https://rffr.leggedrobotics.com/works/viserdex/

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. ### 1. 核心问题与整体含义（研究动机和背景）
灵巧手的手内重定向（In-hand Reorientation）是机器人学中的经典难题。现有的基于视觉的方案通常面临两个瓶颈：
*   **感知-控制差距**：手内运动速度快且手指遮挡严重，单目 RGB 难以稳定估计位姿。
*   **视觉虚实鸿沟（Sim-to-Real Gap）**：传统的基于网格（Mesh）的渲染器难以在保证高吞吐量的同时提供足够的照片级真实感，而高质量的光线追踪渲染又极其耗费计算资源。
**ViserDex** 的目标是开发一个仅依靠**单目 RGB 相机**、能在**消费级硬件**上训练、且对**复杂光照和几何形状**具有鲁棒性的灵巧手重定向系统。

### 2. 方法论：核心思想与关键技术
该框架将任务分解为四个阶段，核心创新在于将 **3D 高斯泼溅（3DGS）** 集成到仿真循环中：

*   **3DGS 预渲染增强（核心创新）**：
    *   利用 3DGS 表示物体，通过操纵高斯球的球谐函数（SH）系数进行“预渲染增强”。
    *   **增强策略**：包括随机噪声、空间聚类增强（模拟局部阴影/污渍）、颜色聚类增强（模拟材质变化）和全局偏移（模拟环境光照/曝光）。
    *   这种方法无需昂贵的光线追踪，即可在 3D 空间生成物理一致的视觉多样性。
*   **感知模型（位姿估计）**：
    *   训练一个基于 ResNet-34 的估计器，预测物体的 9 个几何关键点（8 个顶点 + 1 个质心），通过 Rigid Procrustes 算法恢复 6D 位姿。
*   **控制策略训练**：
    *   **特权教师训练**：在仿真中使用 PPO 算法，利用物体的真实状态（质量、摩擦力、速度等）训练教师策略。
    *   **性能驱动课程学习**：根据代理的连续成功次数，动态增加正则化惩罚、动作延迟和缩短任务时限，提高训练效率。
    *   **学生蒸馏**：将教师策略蒸馏为带有循环神经网络（RNN）和信念编码器的学生策略，使其能处理带有噪声和延迟的观测值。

*   **硬件平台**：16 自由度 Allegro Hand，手腕安装 Intel RealSense D435i 相机。
*   **测试物体**：涵盖从简单几何体（立方体、地球仪）到复杂非凸物体（3D 打印玩具、小黄鸭、药瓶）。
*   **对比基准（Benchmark）**：
    *   **位姿估计对比**：标准平铺渲染（Standard Tiled）、带领域随机化的平铺渲染（DR Tiled）、原生高斯泼溅（Naive GS）。

*   **场景设置**：分为“名义光照”（标准白光）和“对抗光照”（低亮度、动态色调偏移的彩色点光源）。

### 4. 资源与算力
该论文强调了其方法对计算资源的低需求：
*   **GPU 型号**：主要使用单张 **NVIDIA RTX 4090 (24GB)** 或 **RTX 6000 Ada**。
*   **训练时长**：
    *   教师策略：简单物体约 26 小时，复杂物体约 90 小时（双 GPU）。
    *   学生蒸馏：单 GPU 约 16 小时。
*   **效率提升**：相比之前需要 8 张 A40 GPU 运行 60 小时的方案（DeXtreme），ViserDex 在显存效率和训练时间上实现了数量级的优化。

### 5. 实验数量与充分性
*   **实验规模**：针对 5 种不同特性的物体进行了详尽测试。
*   **消融实验**：对四种预渲染增强策略（随机、空间、颜色、全局）分别进行了“留一法”消融，验证了全局偏移对虚实迁移的关键作用。
*   **客观性**：在真实硬件上进行了多次重复实验（每种情况 5 次运行），并使用了 FoundationPose 作为离线真值进行误差分析。实验设计考虑了光照、遮挡和传感器噪声，具有较高的说服力。

### 6. 主要结论与发现
*   **3DGS 的优越性**：基于 3DGS 增强的数据训练出的位姿估计器，在对抗光照下的准确率（56.3%）显著高于传统随机化渲染（47.2%）。
*   **全局偏移至关重要**：消融实验显示，移除全局 SH 偏移会导致对抗环境下的准确率从 56.3% 骤降至 23.6%。
*   **鲁棒性**：系统在真实硬件上实现了平均 25 次以上的连续重定向成功，即使在极端光照下也能保持操作。
*   **感知是瓶颈**：研究发现，控制失败往往源于感知的微小误差累积，而非控制策略本身。

### 7. 优点
*   **高效性**：成功将高昂的视觉仿真成本降低到消费级显卡可负担的水平。
*   **物理一致性**：通过在 3D 高斯空间而非 2D 像素空间做增强，保证了多视角下的视觉一致性。
*   **通用性**：一套超参数和奖励函数即可适用于多种不同几何形状的物体。
*   **抗干扰能力**：信念编码器能有效过滤位姿估计中的瞬时跳变（如 180 度翻转错误）。

### 8. 不足与局限
*   **材质建模限制**：对于表面摩擦力极低或具有特殊标签材质的物体（如药瓶），仿真与现实之间仍存在动力学差距。
*   **泛化性局限**：目前仍属于“实例特定（Instance-specific）”的操纵，即需要为每个物体单独训练/优化高斯模型，尚未实现对完全未知物体的零样本泛化。
*   **触觉缺失**：仅依赖视觉，在手指完全遮挡关键特征或需要感知微小接触力时存在天然限制。
