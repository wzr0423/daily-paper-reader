## 摘要
视觉-语言-动作 (VLA) 模型通过大规模预训练推动了机器人操控的发展，但由于部分可观测性和延迟反馈，其在现实世界中的部署仍面临挑战。强化学习通过价值函数来解决这一问题，价值函数用于评估任务进度并指导策略改进。然而，现有的基于视觉语言模型 (VLM) 的价值模型难以捕捉时间动态，从而损害了长程任务中价值估计的可靠性。在本文中，我们提出了 ViVa，这是一种视频生成式价值模型，它将预训练的视频生成器重新用于价值估计。ViVa 以当前观测和机器人本体感受作为输入，联合预测未来的本体感受和当前状态的标量价值。通过利用预训练视频生成器的时空先验，我们的方法将价值估计建立在预期的具身动态之上，超越了静态快照，使价值与前瞻性内在耦合。通过集成到 RECAP 中，ViVa 在现实世界的纸箱组装任务上取得了显著改进。对所有三项任务的定性分析证实，ViVa 产生了更可靠的价值信号，能够准确反映任务进度。通过利用视频语料库中的时空先验，ViVa 还能泛化到新物体，凸显了视频生成模型在价值估计方面的潜力。

## Abstract
Vision-language-action (VLA) models have advanced robot manipulation through large-scale pretraining, but real-world deployment remains challenging due to partial observability and delayed feedback. Reinforcement learning addresses this via value functions, which assess task progress and guide policy improvement. However, existing value models built on vision-language models (VLMs) struggle to capture temporal dynamics, undermining reliable value estimation in long-horizon tasks. In this paper, we propose ViVa, a video-generative value model that repurposes a pretrained video generator for value estimation. Taking the current observation and robot proprioception as input, ViVa jointly predicts future proprioception and a scalar value for the current state. By leveraging the spatiotemporal priors of a pretrained video generator, our approach grounds value estimation in anticipated embodiment dynamics, moving beyond static snapshots to intrinsically couple value with foresight. Integrated into RECAP, ViVa delivers substantial improvements on real-world box assembly. Qualitative analysis across all three tasks confirms that ViVa produces more reliable value signals, accurately reflecting task progress. By leveraging spatiotemporal priors from video corpora, ViVa also generalizes to novel objects, highlighting the promise of video-generative models for value estimation.

*   **核心问题**：在机器人强化学习（RL）中，如何构建一个能够准确评估任务进度（价值函数）的模型，以指导策略改进。
*   **研究背景**：现有的视觉-语言-动作（VLA）模型在处理长程任务时，往往依赖基于静态图像预训练的视觉语言模型（VLM）来估计价值。
*   **动机**：作者认为价值估计本质上是一个**预测未来**的问题。传统的 VLM 缺乏对物理世界时间动态的理解，仅能识别静态语义，导致在复杂操作中无法准确捕捉任务进度或识别细微的执行错误。

### 2. 方法论：ViVa 视频生成式价值模型
*   **核心思想**：将预训练的**视频生成模型（Video Generator）**重新利用为价值函数。通过预测未来的具身动态（本体感受）来辅助当前状态的价值估计，实现“价值与前瞻性”的内在耦合。
*   **关键技术细节**：
    *   **架构基础**：基于 Wan2.2 视频扩散 Transformer（DiT）。
    *   **多模态潜变量注入**：
        *   **图像**：通过 VAE 编码为潜帧。
        *   **本体感受（Proprioception）**：将 14 维向量通过重复填充（Repeat-padding）映射为潜帧形状。
        *   **标量价值（Value）**：将归一化后的价值通过广播（Broadcast）操作填充为潜帧。
    *   **联合预测任务**：模型输入当前的多视角图像和本体感受，作为“干净”的条件帧；输出目标是预测 $K$ 步后的**未来本体感受**和**当前状态的标量价值**（作为噪声目标进行去噪）。
    *   **奖励定义**：采用一种区分成功与失败的归一化回报函数。成功序列的回报在 $[0, 1)$ 之间（代表进度），失败序列的回报在 $[1, 2)$ 之间，从而在价值空间中为成功和失败建立明确的边界。

    2.  **纸箱组装（Box Packaging）**：长程、多阶段操作。
    3.  **纸巾整理（Toilet Paper Organization）**：涉及撕扯、卷回和贴标签等精细动作。

*   **泛化性测试**：在未见过的物体（如折叠裤子）上测试模型的零样本泛化能力。

### 6. 主要结论与发现
*   **性能提升**：在最复杂的纸箱组装任务中，ViVa 将成功率从 VLM 基准的 58% 提升至 **73%**，吞吐量提升至每小时 14 个任务。
*   **错误检测**：ViVa 对细微的物理错误（如抓取落空、受力不均、异步抬升）非常敏感，价值曲线会在错误发生瞬间产生剧烈下降，而 VLM 模型通常表现迟钝或过拟合。
*   **泛化能力**：得益于大规模视频数据的预训练，ViVa 在处理未见过的物体（裤子）时，依然能产生平滑且符合逻辑的进度信号。

### 7. 优点与亮点
*   **范式创新**：首次明确提出将视频生成器的时空先验作为机器人 RL 价值函数的基础，而非仅仅用于动作预测或环境模拟。
*   **具身耦合**：通过联合预测未来本体感受，强制模型理解机器人的物理运动规律，使价值估计更具“物理常识”。
*   **效率优势**：相比于重型的视觉编码器，利用 DiT 架构处理潜变量在算力和速度上表现更优。

### 8. 不足与局限
*   **实验覆盖范围**：由于真实机器人实验（RECAP 流程）极其耗时，大规模量化实验仅集中在“纸箱组装”一个任务上，其他任务更多是定性分析。
*   **预测步长依赖**：实验表明预测步长 $K$ 对结果影响较大（$K=50$ 最佳），这意味着针对不同动态特性的任务，可能需要手动调优该超参数。
*   **应用限制**：目前主要在双臂操作任务上验证，对于需要极高频率反馈或更复杂环境交互的任务，其 0.18s 的延迟是否足够仍待商榷。
