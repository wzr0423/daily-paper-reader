## 摘要
灵巧操纵需要规划适合物体和任务的抓取构型，随后通过协调的多指控制来执行。然而，为每个物体和任务指定具有密集姿态或接触目标的抓取计划是不切实际的。同时，仅依靠任务奖励的端到端强化学习缺乏可控性，导致用户在发生故障时难以干预。为此，我们提出了 GRIT，这是一个从稀疏分类引导中学习灵巧控制的两阶段框架。GRIT 首先根据场景和任务上下文预测基于分类的抓取规范。以此稀疏指令为条件，策略生成连续的手指运动，在完成任务的同时保持预期的抓取结构。研究结果表明，特定的抓取分类对于特定的物体几何形状更为有效。通过利用这种关系，GRIT 相比基准方法提升了对新物体的泛化能力，并实现了 87.9% 的总成功率。此外，实物实验证明了该框架的可控性，使其能够根据物体几何形状和任务意图，通过高层分类选择来调整抓取策略。

## Abstract
Dexterous manipulation requires planning a grasp configuration suited to the object and task, which is then executed through coordinated multi-finger control. However, specifying grasp plans with dense pose or contact targets for every object and task is impractical. Meanwhile, end-to-end reinforcement learning from task rewards alone lacks controllability, making it difficult for users to intervene when failures occur. To this end, we present GRIT, a two-stage framework that learns dexterous control from sparse taxonomy guidance. GRIT first predicts a taxonomy-based grasp specification from the scene and task context. Conditioned on this sparse command, a policy generates continuous finger motions that accomplish the task while preserving the intended grasp structure. Our result shows that certain grasp taxonomies are more effective for specific object geometries. By leveraging this relationship, GRIT improves generalization to novel objects over baselines and achieves an overall success rate of 87.9%. Moreover, real-world experiments demonstrate controllability, enabling grasp strategies to be adjusted through high-level taxonomy selection based on object geometry and task intent.

*   **核心挑战**：灵巧操纵（Dexterous Manipulation）通常面临两难境地：一是传统的基于密集姿态或接触点规划的方法在面对多样化物体时标注成本极高，难以扩展；二是端到端的强化学习（RL）虽然自动化程度高，但缺乏可控性，用户无法干预抓取方式（如指定用哪几个手指抓）。
*   **研究动机**：人类能根据物体几何形状和任务意图（如“递给我” vs “挤压”）灵活切换抓取策略。论文希望引入**稀疏的抓取分类（Taxonomy）**作为高层引导，既降低了规划难度，又赋予了系统可控性。

### 2. 方法论：GRIT 框架
GRIT 采用两阶段架构，将高层意图与底层执行解耦：
*   **核心思想**：利用人类抓取分类学（Taxonomy）作为中间表示，将复杂的连续控制问题转化为“分类选择 + 分类条件下的控制”。
*   **关键技术细节**：
    1.  **抓取分类库**：基于 Feix 等人的研究，构建了包含 30 种人类抓取类型的库。每种类型定义了参考关节构型、激活的手指链接掩码、参考接触位置和法线。
    2.  **高层抓取规划器**：利用视觉语言模型（VLM，如 Gemini 3）结合场景图像（叠加 3D 坐标轴增强空间感知）和文本指令，预测最合适的抓取分类和手腕朝向。
    3.  **分类条件控制策略**：
        *   **特征提取**：使用 **Basis Point Set (BPS)** 编码局部物体几何特征，并结合手部状态和分类指令。
        *   **乘法复合奖励函数（Multiplicative Composite Reward）**：这是本文的核心创新。不同于传统的加号连接奖励，GRIT 将“分类遵循（Mimic）”作为门控系数。如果动作不符合指定的分类结构，任务奖励会被大幅削减，从而强制策略在保持特定抓取姿态的前提下完成任务。
    4.  **教师-学生蒸馏**：在仿真中使用特权信息（完整点云、接触力）训练教师策略，然后蒸馏给仅使用单视角点云和历史状态的学生策略，以便实机部署。

### 6. 主要结论与发现
*   **性能领先**：GRIT 在新物体上的总成功率达到 **87.9%**，优于 RDG（81.9%）和 GraspXL（86.0%）。
*   **几何相关性**：实验证明抓取分类的有效性高度依赖物体几何。例如，圆柱形物体适合“中等直径抓取”，而扁平物体适合“4 指精密抓取”。
*   **强约束能力**：乘法奖励函数相比加法奖励，能更有效地强制机器人保持指定的抓取姿态（关节误差更低，接触精度更高），且无需繁琐的调参。

### 7. 优点与亮点
*   **可控性强**：通过简单的文本或分类选择即可改变机器人的抓取方式，这在人机交互场景中极具价值。
*   **奖励函数设计巧妙**：乘法奖励结构解决了多目标优化中任务成功与姿态约束之间的权衡难题。
*   **空间感知增强**：在 VLM 输入图像上叠加 3D 轴的方法有效弥补了 2D 模型在 3D 空间推理上的短板。

### 8. 不足与局限
*   **实时反馈缺失**：当前的策略主要依赖初始视觉观察，缺乏在抓取过程中应对物体动态位移的实时闭环视觉反馈。

*   **应用范围**：目前主要集中在“抓取并提起”动作，对于更复杂的后续操纵（如旋转、工具使用）尚未深入探讨。
