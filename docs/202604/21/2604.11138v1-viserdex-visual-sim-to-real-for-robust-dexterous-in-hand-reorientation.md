## 摘要
手内物体重定向需要精确的物体位姿估计，以应对复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有解决方案往往依赖于多摄像头设置或昂贵的光线追踪。我们提出了一种用于单目 RGB 手内重定向的 sim-to-real 框架，该框架集成了 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）以弥合视觉上的 sim-to-real 差距。我们的核心见解是在高斯表示空间中执行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了逼真的、随机化的视觉数据。操作策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型都可以在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指灵巧手上验证了该系统，证明了即使在具有挑战性的光照条件下，也能对五种不同的物体进行鲁棒的重定向。我们的结果表明，高斯泼溅是实现仅靠 RGB 的灵巧操作的一条切实可行的路径。有关硬件部署的视频和其他补充材料，请参阅项目网站：https://rffr.leggedrobotics.com/works/viserdex/

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. #### 1. 核心问题与整体含义
论文针对的是机器人领域极具挑战性的任务：**多指灵巧手的手内物体重定向（In-hand Reorientation）**。
*   **研究动机**：现有的灵巧操作方法要么依赖昂贵的多摄像头阵列、触觉阵列或深度相机，要么在仅使用单目 RGB 图像时表现不佳。
*   **核心挑战**：视觉上的“虚实差异”（Sim-to-Real gap）、操作过程中的严重自遮挡、以及生成高质量合成图像用于训练时面临的巨大计算开销。
*   **整体含义**：ViserDex 旨在证明，通过高效的 3D 高斯泼溅（3DGS）技术和改进的强化学习流程，仅凭单目 RGB 摄像头也能在消费级硬件上训练出足以应对复杂物体和极端光照条件的鲁棒操控策略。

#### 2. 方法论
ViserDex 采用了一个解耦的四阶段流水线：

*   **阶段 I：特权教师训练（RL）**：在仿真环境（Isaac Lab）中，利用 PPO 算法训练一个可以访问物体位姿、速度、接触力等“特权信息”的教师策略。引入了**基于性能的课程学习**，根据成功率动态调整动作延迟、时间窗口和正则化惩罚。
*   **阶段 II：学生策略蒸馏**：将教师策略蒸馏为一个带有循环神经网络（RNN）和信念编码器的学生策略。学生策略仅接收带噪声的本体感受和物体位姿输入，通过重建损失学习推断隐藏状态。
*   **阶段 III：视觉位姿估计器训练（核心创新）**：
    *   **3DGS 集成**：将 3D 高斯泼溅集成到仿真循环中，替代传统网格渲染。
    *   **预渲染增强（Pre-rasterization Augmentations）**：直接在 3D 高斯的属性空间（如球谐系数 SH）进行随机化。通过对高斯点进行空间聚类或颜色聚类，模拟局部阴影、材质变化和全局光照波动，而无需昂贵的光线追踪。
    *   **机器人遮挡处理**：利用物理引擎的低保真深度图对 3DGS 渲染图进行遮挡掩码处理。
*   **阶段 IV：部署**：在真实机器人上，由位姿估计器从 RGB 图像提取位姿，输入给学生策略执行控制。

#### 3. 实验设计
*   **硬件平台**：16 自由度 Allegro Hand，手腕安装 Intel RealSense D435i 摄像头。
*   **测试物体**：5 种具有不同几何特征的物体：立方体（Cube）、地球仪（Globe）、3D 打印玩具（Toy）、橡皮鸭（Rubber Duck）、药瓶（Tablet Bottle）。
*   **实验场景**：
    1.  **常规光照**：标准白色环境光。
    2.  **对抗性光照**：低亮度、动态变色点源光，产生强阴影和高光。
*   **Benchmark 与对比方法**：
    *   **位姿估计对比**：对比了标准平铺渲染（Standard Tiled）、带域随机化的平铺渲染（DR Tiled）以及原生 3DGS。
    *   **操控性能对比**：与著名的 DeXtreme 框架在相同物体上进行对比。
    *   **消融实验**：针对预渲染增强的四个组成部分（随机噪声、空间聚类、颜色聚类、全局偏移）进行“留一法”验证。

#### 4. 资源与算力
论文强调了该方法对硬件的友好性：
*   **GPU 型号**：主要使用单张 NVIDIA RTX 4090 (24GB) 或 RTX 6000 Ada。
*   **训练时长**：
    *   **教师策略**：简单物体约 26 小时，复杂物体约 90 小时（双卡）。
    *   **学生蒸馏**：单卡约 16 小时。
    *   **位姿估计器**：在消费级硬件上即可完成。
*   **效率提升**：渲染吞吐量比 Isaac Lab 默认渲染器快 1.6 倍，显存占用从 34GB 降至 12GB（1024 个并行环境）。

#### 5. 实验数量与充分性
*   **实验规模**：在仿真中使用了 24,576 个并行环境进行 RL 训练。在真实世界中，每个物体和每种光照条件下进行了 5 次完整运行，记录连续成功次数（CS）。
*   **充分性**：实验覆盖了从几何简单到复杂的多种物体，并专门设计了极端光照测试。消融实验深入探讨了 3DGS 增强策略的有效性。
*   **客观性**：使用了 FoundationPose 作为真实世界位姿的基准标签进行定量误差分析（ADD 指标），对比实验设置了相同的网络架构和超参数，确保了公平性。

#### 6. 主要结论与发现
*   **3DGS 的优越性**：基于 3DGS 的预渲染增强能显著提升位姿估计的鲁棒性，尤其是在对抗性光照下，准确率远超传统渲染方法。
*   **全局偏移最关键**：消融实验发现，模拟全局环境变化（Global Shift）对弥合虚实差异贡献最大。
*   **单目 RGB 的潜力**：ViserDex 在立方体重定向任务上达到了平均 35.4 次连续成功，优于之前依赖多摄像头的 DeXtreme（27.8 次）。
*   **感知是瓶颈**：实验发现，即使位姿估计误差很小，也可能导致操控失败，说明灵巧操作对感知精度极其敏感。

#### 7. 优点（亮点）
*   **高效的视觉仿真**：通过在 3DGS 空间做增强，规避了光线追踪的高额开销，同时保持了极高的视觉逼真度。
*   **低算力门槛**：将原本需要 8 张 A40 GPU 的任务简化到单张消费级 4090 上即可完成。
*   **极强的鲁棒性**：首次展示了在剧烈变色和低光照环境下依然能稳定运行的灵巧手重定向系统。

#### 8. 不足与局限
*   **物理建模偏差**：对于某些具有特殊物理属性（如药瓶表面极低摩擦力的标签）的物体，仿真与现实仍存在摩擦力建模不准的问题。
*   **遮挡限制**：虽然系统对部分遮挡有鲁棒性，但在极端遮挡（手指完全覆盖物体特征）时，单目 RGB 仍会失效。
*   **实例特定**：目前的方法仍需要针对特定物体进行 3DGS 扫描和训练，尚未实现完全通用的（General-purpose）物体操控。
