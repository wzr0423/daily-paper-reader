## 摘要
手内物体重定向需要精确的物体位姿估计，以处理复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有的解决方案往往依赖于多摄像头设置或高昂的光线追踪成本。我们提出了一种用于单目 RGB 手内重定向的 sim-to-real 框架，该框架集成了 3D 高斯泼溅（3DGS）以弥合视觉上的 sim-to-real 差距。我们的核心见解是在高斯表示空间中执行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了写实的、随机化的视觉数据。操纵策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型都可以在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指手上验证了该系统，证明了即使在具有挑战性的光照条件下，也能对五种不同的物体进行鲁棒的重定向。我们的结果表明，高斯泼溅是实现仅依靠 RGB 的灵巧操纵的一条实用路径。有关硬件部署的视频和更多补充材料，请参阅项目网站：https://rffr.leggedrobotics.com/works/viserdex/

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. #### 1. 核心问题与整体含义（研究动机和背景）
灵巧手的手内重定向（In-hand Reorientation）是机器人学中的经典难题，要求系统在频繁遮挡、高速运动和复杂接触动力学下精确感知物体位姿。
*   **研究动机**：现有的视觉 Sim-to-Real 方法通常依赖多相机阵列或计算昂贵的光线追踪（Ray Tracing）来生成写实数据，这导致训练成本极高且难以在消费级硬件上普及。
*   **核心问题**：如何在仅使用**单目 RGB 摄像头**的情况下，通过高效的仿真训练，实现对复杂几何形状物体在真实世界（尤其是恶劣光照下）的鲁棒重定向。

#### 2. 方法论：核心思想与关键技术
ViserDex 采用了一种解耦的感知-控制流水线，分为四个阶段：

*   **核心思想**：利用 **3D 高斯泼溅（3DGS）** 替代传统的网格渲染。通过在 3DGS 的表示空间（而非 2D 像素空间）直接进行物理一致的属性增强，生成极具多样性的合成图像。
*   **关键技术细节**：
    1.  **3DGS 集成仿真**：将 3DGS 渲染器嵌入物理仿真循环，通过反转物体变换矩阵实现动态渲染，并利用物理引擎的低精度深度图解决手指遮挡问题。
    2.  **预渲染增强（Pre-rasterization Augmentations）**：直接扰动高斯球的球谐函数（SH）系数。包括：
        *   **随机噪声**：模拟传感器伪影。
        *   **空间聚类增强**：模拟局部阴影或污渍。
        *   **颜色聚类增强**：模拟材质特有的反照率变化。
        *   **全局偏移**：模拟环境光温、曝光和亮度。
    3.  **控制策略训练**：
        *   **特权教师（Teacher）**：在仿真中使用完整状态信息（质量、摩擦力等）通过 PPO 训练。
        *   **学生蒸馏（Student）**：使用带有感知噪声模型的循环神经网络（RNN）学习教师行为，并利用信念编码器（Belief Encoder）重建隐藏状态。
        *   **性能课程学习**：根据平均连续成功次数动态调整正则化惩罚、动作延迟和任务时限。

#### 3. 实验设计
*   **硬件平台**：16 自由度 Allegro Hand，手腕安装单目 Intel RealSense D435i。
*   **实验物体**：5 种物体，涵盖简单几何体（立方体、地球仪）到复杂非凸物体（3D 打印玩具、小黄鸭、药瓶）。
*   **Benchmark 与对比方法**：
    *   **位姿估计对比**：对比了标准平铺渲染（Standard Tiled）、带域随机化的平铺渲染（DR Tiled）以及不带增强的原生 3DGS。
    *   **硬件部署对比**：与著名的 DeXtreme（OpenAI 方案的后续研究）在相同物体上进行对比。
*   **测试场景**：分为**标称光照**（正常白光）和**对抗性光照**（低亮度、动态彩色点光源）。

#### 4. 资源与算力
该论文的一大亮点是**对算力需求极低**：
*   **硬件**：单台工作站，配备 Intel i9 CPU 和单张 **NVIDIA RTX 6000 Ada**（或训练时使用单张 **RTX 4090**）。
*   **训练时长**：
    *   **教师策略**：简单物体约 26 小时，复杂物体约 90 小时（双 GPU）。
    *   **学生蒸馏**：单 GPU 仅需 16 小时。
*   **效率提升**：3DGS 渲染吞吐量比 Isaac Lab 默认渲染器快 **1.6 倍**，显存占用从 34GB 降至 **12GB**。

#### 5. 实验数量与充分性
*   **实验规模**：
    *   针对 5 种物体分别进行了位姿估计精度测试（ADD 指标）。
    *   进行了详细的**消融实验**，逐一移除四种预渲染增强策略，验证了“全局偏移”对 Sim-to-Real 的决定性作用。
    *   真实硬件部署中，每种物体在两种光照下各进行 5 次长序列测试。
*   **充分性评价**：实验设计非常全面，不仅有定量的精度分析，还有针对信念状态（Belief State）抗噪能力的定性分析。对比实验涵盖了当前主流的渲染技术路径，结果具有客观性。

#### 6. 主要结论与发现
*   **3DGS 的优越性**：在 3D 空间直接增强高斯属性比传统的 2D 图像增强更能捕捉物理光照变化。
*   **鲁棒性**：ViserDex 在对抗性光照下仍能保持约 25 次的平均连续成功重定向，而传统渲染方法在此时性能大幅下降。
*   **感知是瓶颈**：实验发现，即使位姿估计精度只有小幅下降，也会导致控制策略的连续成功率出现不成比例的剧减，证明了高频、高精度感知在灵巧操作中的核心地位。

#### 7. 优点（亮点）
*   **高效性**：打破了灵巧手研究依赖大型计算集群（如 8 张 A40 显卡）的现状，证明了消费级显卡也能训练出顶尖性能。
*   **视觉鲁棒性**：通过 3DGS 预渲染增强，成功解决了单目 RGB 在复杂光照和严重遮挡下的感知难题。
*   **通用流水线**：课程学习机制使得同一套超参数可以适用于多种不同几何形状的物体。

#### 8. 不足与局限
*   **实例依赖**：目前的方法仍需要为每个物体提前构建高斯模型（Polycam 扫描），尚未实现对完全未知类别的泛化。
*   **物理建模误差**：对于某些特殊材质（如药瓶标签的极低摩擦力），仿真环境仍存在建模不准的问题，导致该物体的真实表现弱于仿真。
*   **触觉缺失**：虽然视觉很强大，但在极端遮挡下，缺乏触觉反馈仍限制了系统处理精细接触力的能力。
