## 摘要
我们提出了 3D 锚定前瞻规划（3D-ALP），这是一种用于机器人操作的系统 2 推理引擎，它将蒙特卡洛树搜索（MCTS）与作为展开预言机的 3D 一致性世界模型相结合。与仅根据当前摄像机帧评估动作的反应式策略不同，3D-ALP 维护一个持久的相机到世界（c2w）锚点，该锚点在遮挡情况下依然存在，从而能够对不再直接可见的物体位置进行准确的重新规划。在一项需要空间记忆的 5 步序列到达任务（实验 E3）中，3D-ALP 在需要记忆的步骤上实现了 0.650 ± 0.109 的成功率，而贪婪反应式基准仅为 0.006 ± 0.008（Δ=+0.645）；在第 5 步的成功率达到了 0.822，而贪婪基准为 0.000。消融研究（30 个回合，3 个随机种子）表明，树搜索空间记忆是主要的性能驱动因素（+0.533，占增益的 82%），而更深的前瞻规划也带来了额外收益（+0.111，占 17%）。我们还识别并解决了将 UCT-MCTS（应用于树的置信上限 [10]）应用于连续机器人操作时的四种结构性失效模式。

## Abstract
We present 3D-Anchored Lookahead Planning (3D-ALP), a System 2 reasoning engine for robotic manipulation that combines Monte Carlo Tree Search (MCTS) with a 3D-consistent world model as the rollout oracle. Unlike reactive policies that evaluate actions from the current camera frame only, 3D-ALP maintains a persistent camera-to-world (c2w) anchor that survives occlusion, enabling accurate replanning to object positions that are no longer directly observable. On a 5-step sequential reach task requiring spatial memory (Experiment E3), 3D-ALP achieves 0.650 0.109 success rate on memory-required steps versus 0.006 0.008 for a greedy reactive baseline (Δ=+0.645), while step 5 success reaches 0.822 against 0.000 for greedy. An ablation study (30 episodes, 3 seeds) isolates tree search spatial memory as the primary driver (+0.533, 82% of gain) with additional benefit from deeper lookahead (+0.111, 17%). We also identify and resolve four structural failure modes in applying UCT-MCTS (Upper Confidence Bounds applied to Trees [10]) to continuous robotic manipulation.

### 1. 核心问题与整体含义（研究动机和背景）
现代机器人操纵系统主要依赖视觉-语言-动作（VLA）模型，这些模型通常是“反应式”的（System 1），即直接将当前图像映射为动作。这种机制存在一个根本缺陷：**缺乏物体恒存性（Object Permanence）**。当物体被遮挡或移出视野时，机器人会“忘记”其位置，导致多步操纵任务失败。论文提出了 **3D-ALP** 框架，旨在为机器人引入“系统 2”推理能力，通过持久的空间记忆和前瞻性规划，解决遮挡环境下的长程操纵问题。

### 2. 方法论：核心思想与技术细节
3D-ALP 的核心是将**蒙特卡洛树搜索（MCTS）**与**3D 一致性世界模型**相结合。其关键技术组件包括：
*   **持久化 3D 锚点**：系统维护一个 SE(3) 状态的相机到世界（c2w）锚点。每执行一次物理动作，通过正向运动学（FK）更新锚点，而不是重置。这确保了即使物体不可见，其坐标信息仍保留在搜索树中。
*   **3D 一致性世界模型（InSpatio-WorldFM）**：作为 MCTS 的预言机（Oracle），根据给定的 c2w 查询渲染预测帧，允许机器人在“想象”的 3D 空间中进行展开（Rollout）。
*   **混合几何-语义评分器**：针对视觉语言模型（VLM）存在的“深度盲区”（即无法区分 2D 重叠与 3D 接触），该评分器将 VLM 的语义得分与运动学深度惩罚相结合，强制规划器关注几何上的真实接近度。
*   **MCTS 的四项结构性修复**：
    1.  **F1（零动作陷阱）**：使用 Max-Q 值选择而非仅靠访问次数，防止机器人原地踏步。
    2.  **F2（深度衰减）**：在重根（Re-rooting）后递归重置深度，保持前瞻视野。
    3.  **F3（均值惩罚）**：采用 Max-MCTS，反向传播最大值而非平均值，避免最优路径被差路径稀释。
    4.  **F4（UCB1 常数校准）**：将探索常数 $c$ 从 1.414 调低至 0.02，以匹配连续空间中微小的运动学得分差异。

### 3. 实验设计

### 6. 主要结论与发现
*   **性能飞跃**：在需要记忆的步骤中，3D-ALP 成功率为 **0.650**，而反应式基准仅为 **0.006**。在最具挑战性的第 5 步，3D-ALP 达到了 **82.2%** 的成功率，基准线则彻底崩溃（0%）。

*   **VLM 局限性**：实验证实了现有的 VLM（如 Florence-2）在处理合成渲染图的深度信息时表现较差，必须引入几何约束。

*   **架构创新**：成功将 3D 空间一致性引入 MCTS 框架，解决了机器人领域长期存在的“物体恒存性”难题。
*   **工程落地**：针对连续动作空间应用 MCTS 提出的四项修复方案具有很强的实用参考价值。
*   **模块化**：系统组件（世界模型、评分器、规划引擎）解耦，易于替换更先进的模型（如 JEPA）。

### 8. 不足与局限
*   **渲染瓶颈**：世界模型的渲染速度（2.4秒/帧）远慢于实时要求，限制了 MCTS 的搜索宽度和深度。

*   **环境局限**：目前仅在 MuJoCo 仿真中验证，尚未在具有复杂光影、动态障碍物的真实物理环境中测试。
*   **任务单一**：实验主要集中在“到达”任务，未涉及复杂的抓取、放置或非刚体操作。
