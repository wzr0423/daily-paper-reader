## 摘要
手内物体重定向需要精确的物体位姿估计，以处理复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有的解决方案往往依赖于多摄像头设置或高昂的光线追踪成本。我们提出了一种用于单目 RGB 手内重定向的 sim-to-real 框架，该框架集成了 3D 高斯泼溅（3DGS）以弥合视觉上的 sim-to-real 差距。我们的核心见解是在高斯表示空间中执行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了写实的、随机化的视觉数据。操纵策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型都可以在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指手上验证了该系统，证明了即使在具有挑战性的光照条件下，也能对五种不同的物体进行鲁棒的重定向。我们的结果表明，高斯泼溅是实现仅依靠 RGB 的灵巧操纵的一条实用路径。有关硬件部署的视频和更多补充材料，请参阅项目网站：https://rffr.leggedrobotics.com/works/viserdex/

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. 灵巧手内重定向（In-hand Reorientation）是机器人领域极具挑战性的任务，要求在频繁遮挡和动态变化中精确估计物体位姿。
*   **研究动机**：现有的单目 RGB 方案在虚实迁移（Sim-to-Real）中面临巨大的“视觉鸿沟”。传统的网格渲染（Mesh-based rendering）难以兼顾高保真度和计算效率，而高质量的光线追踪（Ray-tracing）在强化学习（RL）所需的大规模数据生成中成本过高。
*   **核心目标**：开发一个仅依靠单目 RGB 摄像头、能在消费级硬件上训练、且对复杂几何体和极端光照具有鲁棒性的灵巧操作框架。

### 2. 方法论：核心思想与关键技术
ViserDex 采用模块化设计，将感知与控制解耦，分为四个阶段：
*   **基于 3DGS 的视觉表示**：利用 3D Gaussian Splatting (3DGS) 替代传统网格渲染。核心创新是**预渲染增强（Pre-rasterization Augmentations）**：直接在 Gaussian 属性（如球谐函数 SH 系数）上进行随机化，模拟光照、材质和环境变化，而无需昂贵的光线追踪。
*   **特权教师训练（Privileged Teacher）**：在仿真环境中使用 PPO 算法训练一个能访问完整状态（物体速度、接触力等）的教师策略。引入了**基于性能的课程学习**，根据成功率动态调整任务难度（如延迟、惩罚项）。
*   **学生策略蒸馏**：将教师策略蒸馏为仅依赖噪声观测（本体感受+视觉位姿）的循环神经网络（RNN）学生策略，利用信念编码器（Belief Encoder）处理观测噪声和遮挡。
*   **视觉位姿估计器**：训练一个 ResNet-34 模型，通过 3DGS 生成的增强数据回归物体的 2.5D 关键点，进而通过 Rigid Procrustes 算法求解 6D 位姿。

*   **测试物体**：包括立方体（Cube）、3D 打印玩具、小黄鸭、药瓶、地球仪（涵盖了从简单几何到复杂非凸形状）。
*   **Benchmark 与对比方法**：

### 5. 实验数量与充分性
*   **实验规模**：针对 5 种不同特性的物体进行了详尽测试，每种物体在真实硬件上进行 5 次独立运行。
*   **消融实验**：非常充分。作者对预渲染增强的四个组成部分（随机噪声、空间聚类、颜色聚类、全局偏移）分别进行了“留一法”消融，验证了各部分对鲁棒性的贡献。
*   **客观性**：通过引入“对抗性光照”这一极端变量，客观地展示了模型在超出分布（OOD）情况下的生存能力。

### 6 主要结论与发现
*   **3DGS 的优越性**：在 Gaussian 空间进行增强比传统的 2D 图像增强更能捕捉物理一致的视觉变化。
*   **全局偏移（Global Shift）最关键**：消融实验证明，模拟环境光照的全局偏移是弥合视觉 Sim-to-Real 鸿沟最重要的因素。
*   **感知是瓶颈**：实验发现，即使位姿估计精度下降较小，也会导致控制成功率大幅下降，说明灵巧操作对感知误差极度敏感。
*   **鲁棒性**：系统在常规光照下平均可实现 37.6 次连续重定向，在极端对抗光照下仍能维持约 25 次。

### 7. 优点与亮点
*   **高效性**：首次证明了复杂的灵巧操作视觉策略可以在单张消费级 GPU 上完成训练。
*   **视觉鲁棒性**：通过 3DGS 预渲染增强，解决了单目 RGB 在复杂光照和遮挡下的失效问题。
*   **通用性**：一套超参数和奖励函数即可适用于多种不同几何形状的物体，无需针对特定物体调优。

### 8. 不足与局限
*   **摩擦力建模缺失**：在药瓶（Tablet Bottle）实验中表现较差，原因是无法建模瓶身标签带来的极低表面摩擦力。
*   **泛化性限制**：目前仍属于实例级（Instance-specific）操作，即需要为每个物体单独训练位姿估计器和策略，尚未实现对任意未知物体的通用泛化。
*   **触觉缺失**：仅依赖视觉，在完全遮挡或需要感知微小接触力的情况下存在天然局限。
