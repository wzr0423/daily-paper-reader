## 摘要
手内物体重定向需要精确的物体位姿估计，以应对复杂的任务动力学。虽然 RGB 感知为位姿跟踪提供了丰富的语义线索，但现有的解决方案往往依赖多摄像头设置或高成本的光线追踪。我们提出了一个用于单目 RGB 手内重定向的 sim-to-real 框架，该框架集成了 3D 高斯泼溅（3DGS）以弥合视觉上的 sim-to-real 差距。我们的核心见解是在高斯表示空间中进行领域随机化：通过对 3D 高斯应用物理一致的预渲染增强，我们为物体位姿估计生成了具有照片级真实感的随机化视觉数据。操纵策略采用基于课程的强化学习和教师-学生蒸馏进行训练，从而实现了复杂行为的高效学习。重要的是，感知和控制模型均可在消费级硬件上独立训练，无需大型计算集群。实验表明，在具有挑战性的视觉环境中，使用 3DGS 数据训练的位姿估计器优于使用传统渲染数据训练的估计器。我们在配备 RGB 摄像头的物理多指灵巧手上验证了该系统，展示了即使在严苛的光照条件下，也能对五种不同物体进行鲁棒的重定向。我们的结果表明，高斯泼溅是实现仅基于 RGB 的灵巧操纵的一条切实可行的路径。有关硬件部署视频及更多补充材料，请访问项目网站：https://rffr.leggedrobotics.com/works/viserdex/。

## Abstract
In-hand object reorientation requires precise estimation of the object pose to handle complex task dynamics. While RGB sensing offers rich semantic cues for pose tracking, existing solutions rely on multi-camera setups or costly ray tracing. We present a sim-to-real framework for monocular RGB in-hand reorientation that integrates 3D Gaussian Splatting (3DGS) to bridge the visual sim-to-real gap. Our key insight is performing domain randomization in the Gaussian representation space: by applying physically consistent, pre-rendering augmentations to 3D Gaussians, we generate photorealistic, randomized visual data for object pose estimation. The manipulation policy is trained using curriculum-based reinforcement learning with teacher-student distillation, enabling efficient learning of complex behaviors. Importantly, both perception and control models can be trained independently on consumer-grade hardware, eliminating the need for large compute clusters. Experiments show that the pose estimator trained with 3DGS data outperforms those trained using conventional rendering data in challenging visual environments. We validate the system on a physical multi-fingered hand equipped with an RGB camera, demonstrating robust reorientation of five diverse objects even under challenging lighting conditions. Our results highlight Gaussian splatting as a practical path for RGB-only dexterous manipulation. ### 1. 核心问题与整体含义（研究动机和背景）
灵巧手内物体重定向（In-hand Reorientation）是机器人学中的经典难题。其核心挑战在于：
*   **感知瓶颈**：手内操作伴随剧烈的自我遮挡和快速运动，单目RGB难以提供稳定的位姿估计。
*   **虚实迁移（Sim-to-Real）鸿沟**：传统基于网格（Mesh）的渲染器难以兼顾照片级真实感与高吞吐量的训练需求，导致视觉模型在真实世界（尤其是复杂光照下）表现不佳。
*   **计算成本**：现有的鲁棒方案（如OpenAI的Dextreme）通常依赖大规模计算集群进行自动领域随机化（ADR）。
**ViserDex** 旨在通过集成 **3D高斯泼溅（3DGS）** 技术，在消费级硬件上实现仅依赖单目RGB的鲁棒灵巧手操作。

### 2. 方法论：核心思想与关键技术
该框架将任务分解为感知与控制两个独立但协同的模块：

*   **基于3DGS的预渲染增强（Pre-rasterization Augmentations）**：
    *   **核心思想**：不直接在2D图像上做增强，而是在3D高斯表示空间中，通过扰动球谐函数（SH）系数来模拟光照、材质和环境变化。
    *   **关键技术**：为了保持光度一致性，对高斯点进行聚类（空间聚类、颜色聚类），然后对聚类组应用随机噪声、空间偏移、颜色偏移和全局偏移。
    *   **物理一致性**：通过物理模拟器的低保真深度图对3DGS渲染图进行遮挡处理（Masking），解决手指遮挡物体的视觉一致性问题。
*   **控制策略训练**：
    *   **特权教师训练**：在仿真中使用PPO算法训练一个拥有全状态信息（物体速度、接触力等）的教师策略。
    *   **性能驱动课程学习**：根据成功率动态调整正则化惩罚、动作延迟和任务时间窗口，提高训练效率。
    *   **学生策略蒸馏**：将教师策略蒸馏为一个基于循环神经网络（RNN）的学生策略，仅接收带噪声的本体感受和视觉位姿输入。

*   **测试物体**：涵盖五种不同几何特征的物体：立方体（Cube）、3D打印玩具（Toy）、小黄鸭（Rubber Duck）、药瓶（Tablet Bottle）、地球仪（Globe）。
*   **Benchmark与对比方法**：

*   **光照条件**：分为标称光照（Nominal）和对抗性光照（Adversarial，低亮度、动态色调偏移）。

### 4. 资源与算力
该论文强调了其方法对计算资源的友好性：
*   **硬件**：单台工作站，配备 **NVIDIA RTX 6000 Ada** 或 **RTX 4090** GPU。
*   **训练时长**：
    *   **教师策略**：简单物体约26小时，复杂物体约90小时（单/双GPU）。
    *   **学生蒸馏**：单GPU约16小时。
    *   **渲染效率**：3DGS渲染比传统渲染器快1.6倍，显存占用仅为1/3（12GB vs 34GB）。

### 5. 实验数量与充分性
*   **实验规模**：进行了大量的仿真评估（256个随机环境）和真实硬件部署（每种物体/光照条件下进行5次长序列运行）。
*   **消融实验**：针对四种不同的预渲染增强策略（随机噪声、空间聚类、颜色聚类、全局偏移）分别在正常和对抗光照下做了详尽的消融实验。
*   **客观性**：使用了FoundationPose作为真实世界位姿的基准标签，并报告了ADD（模型点平均距离）和严格的旋转/平移精度指标，实验设计较为客观公平。

### 6. 主要结论与发现
*   **3DGS的优越性**：基于3DGS生成的合成数据训练的位姿估计器，在真实世界中的表现显著优于传统Mesh渲染数据。
*   **增强的重要性**：在对抗性光照下，**全局偏移（Global Shift）** 增强是防止模型崩溃的关键，而聚类增强提升了局部特征的鲁棒性。
*   **感知是瓶颈**：实验发现，即使位姿估计精度仅有小幅下降，也会导致控制成功率的大幅降低，证明了高频、高精度视觉反馈对灵巧操作的决定性作用。
*   **性能表现**：在真实硬件上实现了平均超过25次连续成功重定向，地球仪物体甚至达到了单次超过200次成功。

### 7. 优点与亮点
*   **高效的Sim-to-Real路径**：通过3DGS绕过了昂贵的光线追踪，同时获得了比传统渲染更高的视觉保真度。
*   **创新的增强策略**：提出的“预渲染增强”在保持3D几何一致性的同时，赋予了静态3DGS模型动态的光照适应能力。
*   **低门槛训练**：证明了复杂的灵巧操作任务可以在单台消费级工作站上完成，无需数千个CPU核心的集群。

### 8. 不足与局限
*   **材质建模限制**：对于表面摩擦力极低或具有特殊反射特性的物体（如带标签的药瓶），仿真与现实之间仍存在动力学差距。
*   **泛化性有限**：目前的方法仍属于“实例级（Instance-specific）”操作，即需要为每个物体单独训练或微调模型，尚未实现通用的类别级泛化。
*   **传感器融合不足**：虽然视觉很强大，但在完全遮挡或需要精细力控的场景下，缺乏触觉传感器的集成。
